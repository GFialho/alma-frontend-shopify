═══════════════════════════════════════════════════════════════
  HOW IT WORKS
═══════════════════════════════════════════════════════════════

AUTOMATIC DETECTION:
┌─────────────────────────────────────────┐
│ Product has selling plans?              │
│   ├─ YES → Show subscription selector   │
│   └─ NO  → Normal one-time purchase    │
└─────────────────────────────────────────┘

CUSTOMER FLOW:
1. Customer visits product page
2. Sees subscription option (if available)
3. Selects subscription or one-time
4. Adds to cart
5. Cart shows subscription details
6. Checkout creates subscription
7. Customer account shows subscription

═══════════════════════════════════════════════════════════════
  NEXT STEPS FOR YOU
═══════════════════════════════════════════════════════════════

STEP 1: Set Up Selling Plan
  • Go to Shopify Admin → Apps → Subscriptions
  • Create new subscription plan
  • Set frequency (e.g., monthly)
  • Set discount (e.g., 20%)
  • Add products to plan

STEP 2: Test It
  • Visit product page
  • Subscription selector should appear
  • Select subscription option
  • Add to cart and complete test order

STEP 3: Customize (Optional)
  • Edit colors in section-alma-product.css
  • Change messages in alma-product.liquid
  • Adjust layout as needed

STEP 4: Go Live! 🚀
